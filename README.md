# سجل أهدافي

تطبيق ويب (PWA) لإدارة الأهداف والمهام اليومية للأفراد والفرق: لوحة تحكم، أهداف بتقدّم لحظي، مهام بأولويات وتكليف، تقويم، تقارير، صلاحيات لكل هدف، سجل نشاط، ومساعد تخطيط. يعمل بدون إنترنت ويُثبَّت كتطبيق.

🔗 <https://abdelrahmanfikry.github.io/test3/>

## المميزات

| المجال | التفاصيل |
|---|---|
| **لوحة التحكم** | تحية بالاسم، عبارة اليوم، مؤشرات (اليوم/متأخرة/أُنجز هذا الأسبوع/سلسلة الإنجاز/الأهداف/النسبة)، «ركّز اليوم»، أهداف قريبة من موعدها، مهامي المكلّف بها |
| **الأهداف** | كروت بلون وتصنيف وأولوية وحلقة تقدّم، فلاتر (نشط/متأخر/مكتمل/مؤرشف)، بحث وترتيب، أرشفة، عام/خاص، **لوحة جانبية** لكل هدف بمهامه وإضافة سريعة ومقارنة الإنجاز بالوقت المنقضي |
| **المهام** | إضافة سريعة تفهم «غداً» و«!عالي»، تجميع (الموعد/الهدف/الأولوية)، فلاتر (الهدف/المكلّف/الأولوية/الحالة)، سحب لإعادة الترتيب **محفوظ**، تعديل حقيقي بدون حذف وإعادة إنشاء، تراجع بعد الإنجاز، احتفال عند إكمال هدف |
| **التقويم** | شهر بنقاط المهام وأعلام مواعيد الأهداف، اختيار يوم لعرض مهامه وإضافة مهمة فيه |
| **التقارير** | إنجاز 8 أسابيع، تقدّم كل هدف، حسب المكلّف، حسب التصنيف، تصدير CSV وطباعة |
| **الفريق (مشرف)** | كل المستخدمين بأدوارهم وإحصائياتهم، ترقية/إزالة إشراف، **إدارة الوصول** لكل هدف (خاص/عام/قائمة مسموح/قائمة محجوبة) |
| **سجل النشاط** | خط زمني لكل إنشاء/تعديل/حذف مع الفاعل والوقت وفلترة بالنوع |
| **المساعد** | يجيب ببياناتك: مهام اليوم، المتأخر، الأسبوع، الإحصائيات، أقرب هدف، ويفتح نوافذ الإضافة |
| **الحساب والتفضيلات** | اسم العرض، تغيير كلمة المرور، مظهر فاتح/داكن/تلقائي، عرض مكثّف، تنبيهات المتصفح للمستحق اليوم |
| **عام** | بحث سريع (Ctrl+K)، اختصارات كيبورد، RTL كامل، موبايل (شريط سفلي + FAB + لوحة جانبية)، PWA أوفلاين، حماية XSS، وضع تجريبي بدون تسجيل |

## Firebase

نفس مشروع النسخة القديمة (`to-do-aeb49`) ونفس المجموعات، فالحسابات والبيانات الحالية تعمل كما هي:

| المجموعة | الحقول المهمة |
|---|---|
| `userProfiles/{uid}` | `email, role (user/admin), displayName, photoURL, lastSeen` |
| `goals/{id}` | `name, startDate, endDate, note, progress, createdBy, assignedUserIds[], visibility, visibilityMode, blockedUserIds[]` + جديد: `category, priority, color, archived` |
| `tasks/{id}` | `name, dueDate, goalId, completed, assignedToUid, assignedToEmail, createdBy` + جديد: `priority, notes, order, completedAt` |
| `activity/{id}` | سجل النشاط (+ نسخة تحت كل هدف/مهمة) |
| `mail/{id}` | رسائل لإضافة **Trigger Email** (اختيارية) |

انشر [firestore.rules](firestore.rules) من Firebase Console. لتفعيل الدخول بجوجل: Authentication → Sign-in method → Google.

## التشغيل محلياً

```bash
python -m http.server 8092
```
