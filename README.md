# سجل أهدافي

تطبيق ويب (PWA) لإدارة الأهداف والمهام اليومية للأفراد والفرق: لوحة تحكم، أهداف بتقدّم لحظي، مهام بأولويات وتكليف، تقويم، تقارير، صلاحيات لكل هدف، سجل نشاط، ومساعد تخطيط. يعمل بدون إنترنت ويُثبَّت كتطبيق.

🔗 <https://abdelrahmanfikry.github.io/test3/>

## المميزات

### الإصدار 6: مظهر Odoo وصيانة
| المجال | التفاصيل |
|---|---|
| **مظهر Odoo (افتراضي)** | شريط علوي بلون العلامة مع أيقونة التطبيق وقوائم نصية وقائمة المستخدم، درج تطبيقات بشبكة أيقونات ملوّنة، شريط أدوات مدمج في لوحة التحكم، شريط تقدّم لكل عمود كانبان (منجز/متأخر/عالي)، صفحة دخول ببطاقة واحدة، لوحة تحكم بمسار تنقّل وأزرار «جديد»، قوائم مهام مسطّحة كجدول، كانبان بأعمدة مفتوحة وبطاقات بيضاء، بطاقة المهمة كنموذج «ورقة» مع شريط مراحل، والشريط الجانبي كدرج تطبيقات. تبديل إلى «كلاسيكي» من الإعدادات (`css/odoo.css`) |
| **تقسيم الشاشات** | `js/views.js` أصبح ملف تجميع، والشاشات في `js/views/` (shared, dashboard, goals, tasks, calendar, reports, team, activity, settings, modals) |
| **اختبار واجهة آلي** | `npm run test:ui` بـ Playwright: يفتح الوضع التجريبي، يزور كل الصفحات، يجرّب الإضافة السريعة وبطاقة المهمة ولوحة الأوامر والإشعارات ووضع الاجتماع والموبايل، ويفشل عند أي خطأ console. يعمل قبل الرفع تلقائياً إن كان Playwright مثبّتاً |
| **مراقبة الأخطاء** | `js/monitor.js` يلتقط الأخطاء غير المعالجة، يعرضها في الإعدادات، يرسلها إلى `clientErrors` ليراها المشرف في صفحة الفريق، ودعم Sentry اختياري عبر `SENTRY_DSN` |


### الإصدار 5: تعاون لحظي وذكاء وأتمتة
| المجال | التفاصيل |
|---|---|
| **إشعارات عبر الأجهزة** | مجموعة `notifications` في Firestore: تكليف، ذكر في تعليق، تعليق، إنجاز، تغيّر مرحلة — تُقرأ من كل الأجهزة وتُعلَّم كمقروءة. Web Push اختياري عبر FCM (مفتاح VAPID في `js/data.js` + مجلد `functions/`) |
| **حضور مباشر** | من يتصفح المشروع الآن (`presence/{uid}`) ومؤشر «يكتب…» في المحادثة |
| **مشاركة برابط** | `share.html?t=TOKEN` يعرض لقطة للقراءة فقط من `shares/{token}` بدون حساب، مع تحديث اللقطة وإلغاء الرابط |
| **الجانت** | خطوط الاعتماديات (محجوبة بـ)، والخط الأحمر للتعارض، وإزاحة تلقائية للمهام التابعة عند التأخير (بعد التأكيد) |
| **التكلفة** | سعر ساعة وطاقة أسبوعية لكل عضو (صفحة الفريق)، ميزانية لكل مشروع، تكلفة = الساعات × السعر في نظرة المشروع والتقارير |
| **أتمتة المراحل** | تكليف تلقائي عند دخول مرحلة، تنبيه عند تجاوز حد WIP |
| **جدول محوري** | مشروع × عضو بقياس مفتوحة/منجزة/متأخرة/كل/ساعات |
| **قوالب مهام** | حفظ أي مهمة كقالب (قائمة مراجعة، ساعات، مدة) وإنشاء منها في أي مشروع |
| **حمل العمل الذكي** | ساعات الأسبوع القادم مقابل الطاقة، تنبيه «مثقل» واقتراح إعادة التوزيع إلى الأقل حملاً |
| **ملخص أسبوعي** | معاينة وإرسال بالبريد (Trigger Email)، وإرسال تلقائي أسبوعياً؛ نسخة مجدولة في `functions/` |
| **مساعد Claude** | مفتاح API يُحفظ محلياً فقط؛ يجيب عن بياناتك، يبني خططاً بإجراءات JSON تُنفَّذ بعد تأكيدك، ويستخرج المهام من الصور |
| **صوت وصورة** | إدخال صوتي (Web Speech) في الإضافة السريعة والمساعد، ومهام من صورة |
| **PWA** | اختصارات على الأيقونة (مهمة، اليوم، المهام، تركيز) واستقبال المشاركة من النظام (`share_target`)، عدّاد الكتابات غير المرفوعة أوفلاين |
| **وضع الاجتماع** | خطة اليوم بخط كبير على شاشة كاملة مع إنجاز مباشر (`T`) |
| **إنجليزية (جزئية)** | القوائم والعناوين والأزرار الرئيسية مع اتجاه LTR؛ النصوص التفصيلية تبقى بالعربية |
| **الجودة** | `npm test` (16 اختباراً لـ analytics/model/utils) ويعمل تلقائياً قبل كل رفع عبر `.githooks/pre-push`؛ دخول Google بإعادة التوجيه على الموبايل؛ نسخة احتياطية أسبوعية تلقائية إلى Storage |


### الإصدار 4: سرعة ومزايا يومية
| المجال | التفاصيل |
|---|---|
| **سرعة التحميل** | Firebase يُحمَّل فقط خارج الوضع التجريبي، وSortable/Chart.js/Storage عند الحاجة فقط (`js/lib.js`)، `modulepreload` لكل الوحدات، شاشة بداية فورية وهياكل تحميل (skeleton)، Service Worker يتجاوز كاش HTTP عند التحديث ويُعلمك بالإصدار الجديد، وفهرس مهام مُخزَّن (memo) |
| **الإشعارات** | جرس في الشريط العلوي: متأخرة، اليوم، تكليفات جديدة، أنشطة مستحقة، مواعيد المشاريع والمعالم؛ تعليم كمقروء؛ اختصار `I` |
| **وضع التركيز 🍅** | مؤقّت بومودورو (مدد قابلة للضبط) مرتبط بمهمة، يسجّل كل جلسة كساعات على المهمة، إنجاز المهمة من الشاشة، عداد جلسات اليوم، اختصار `F` |
| **التحديد المتعدد** | في قائمة المهام: إنجاز / أولوية / موعد / مكلّف / نقل لمشروع / حذف دفعة واحدة |
| **سلة المحذوفات** | حذف ناعم للمهام والمشاريع مع «تراجع» فوري، استعادة أو حذف نهائي، وتنظيف تلقائي بعد 30 يوماً (`#trash`) |
| **التقويم** | عرض أسبوعي بالسحب بين الأيام، بداية الأسبوع (سبت/اثنين)، تصدير `.ics` لـ Google Calendar / Outlook |
| **لوحة التحكم** | خريطة حرارية للإنجاز (12 أسبوعاً)، الأيام السبعة القادمة، عبء العمل على الفريق |
| **التقارير** | السرعة الأسبوعية، الالتزام بالمواعيد، الساعات المسجّلة لكل عضو ومشروع، جدول حسب المشروع |
| **الفريق** | حالة الاتصال (آخر ظهور < 10 دقائق)، مفتوحة/متأخرة/ساعات الأسبوع، بطاقة العضو بمهامه وتكليف سريع، دعوة بالبريد؛ وإصلاح وميض الصفحة (حلقة إعادة رسم) |
| **المهام** | تأجيل بنقرة، رابط مباشر `#task/<id>`، نسخ المهمة، سحب على الموبايل (يمين = إنجاز، يسار = تأجيل) |
| **المشاريع** | مفضلة في القائمة الجانبية، نسخ المشروع، تصدير JSON، رابط مباشر |
| **لوحة الأوامر** | `Ctrl+K`: بحث ضبابي عربي/إنجليزي في المهام والمشاريع والتاجز والأعضاء + أوامر + الأخيرة + تنقل بالأسهم |
| **الإعدادات** | لون رئيسي، حجم خط، بداية الأسبوع، الصفحة الافتتاحية، مدد التركيز، نسخة احتياطية JSON **واستيراد**، تحديث التطبيق، «ما الجديد» |
| **عام** | شريط عدم الاتصال، اختصارات `?`، تقليل الحركة، تركيز واضح للكيبورد |

## Firebase

نفس مشروع النسخة القديمة (`to-do-aeb49`) ونفس المجموعات، فالحسابات والبيانات الحالية تعمل كما هي:

| المجموعة | الحقول المهمة |
|---|---|
| `userProfiles/{uid}` | `email, role (user/admin), displayName, photoURL, lastSeen` + `savedFilters[], personalStages[], personalStageMap, favorites[]` |
| `goals/{id}` | `name, startDate, endDate, note, progress, createdBy, assignedUserIds[], visibility, visibilityMode, blockedUserIds[]` + جديد: `category, priority, color, archived, stages[], tags[], milestones[], manager, plannedHours, template` · حذف ناعم: `deleted, deletedAt, deletedBy` |
| `tasks/{id}` | `name, dueDate, goalId, completed, assignedToUid, assignedToEmail, createdBy` + جديد: `priority, notes, order, completedAt, stageId, parentId, assignedUserIds[], tags[], starred, startDate, blockedBy[], plannedHours, timesheets[], checklist[], activities[], attachments[], recurrence` · حذف ناعم: `deleted, deletedAt, deletedBy, deletedWithGoal` · تعليقات في `tasks/{id}/messages` |
| `activity/{id}` | سجل النشاط (+ نسخة تحت كل هدف/مهمة) |
| `mail/{id}` | رسائل لإضافة **Trigger Email** (اختيارية) |

انشر [firestore.rules](firestore.rules) و[storage.rules](storage.rules) من Firebase Console (الإصدار 5 يضيف مجموعات notifications و presence و taskTemplates و shares) (قراءة المهام متاحة لأي مستخدم مسجّل لأن استعلامات المجموعة لا يمكن تقييدها بصلاحيات الهدف؛ الواجهة تعرض فقط مهام المشاريع المرئية). لتفعيل الدخول بجوجل: Authentication → Sign-in method → Google.

## الاختبارات
